# crackedbuilder.com

Teaser site for cracked builder — a small lab that builds fast, fails faster, and ships what survives.

## Stack
- Single static `index.html` (inline CSS + JS)
- Deployed via GitHub Pages
- Custom domain: `crackedbuilder.com`

## Files
- `index.html` — the entire site
- `favicon.svg` — brand mark (acid-green dot)
- `CNAME` — tells GitHub Pages the custom domain

## Edit + deploy
Push to `main`. GitHub Pages auto-publishes within ~30s.
